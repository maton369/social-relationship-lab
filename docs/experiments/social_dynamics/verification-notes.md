# 操作と結果の確認記録

## 実施条件

- macOS / TouchDesigner 2025.33230 / 内蔵Python 3.11.15。
- 元の作業セッションとは別に、MCPブリッジを入れた一時検証プロジェクトを起動した。配布用TOEにはブリッジを含めない。
- TouchDesignerでは仮想マウスから実際のPanel Executeコールバックを発火させて操作した。単にボタンのラベルを変更したものではない。
- 12条件の再現可能な操作は `experiments/td_ui_checks.py`、判定は `ui_checks.json`。パネル上の協力・攻撃・噂、リセット、ステップ、開始・一時停止、左右の人物選択、出力を確認した。
- `unit_checks.json`：新規8件を含む40件がTouchDesigner内で通過。

## 実際に見つけた問題

グラフの右クリック時のUV座標更新が無効だった。左クリックで選択した座標を使ってしまう可能性があったため、グラフと親パネルの `uvbuttonsright` を有効化した。その後、右クリックで指定した人物が対象になることを確認した。

最初の実時間再生確認ではMCP要求が途中切断され、続けて接続拒否になった。原因は確定できなかった。検証用プロジェクトを開き直し、HTTP要求の寿命と実時間再生の処理を分けるためにTouchDesigner内部タイマーで検査した。

- `real_time_playback.json`：STEP 0→7へ自動進行し、時間指定で停止。エラーなし。
- `real_time_pause_button.json`：実際の開始ボタンでSTEP 7→14へ自動進行し、実際の一時停止ボタンで停止。停止時の分析を含め約3.7秒。エラーなし。
- 中断がなかったように扱わず、初回の切断と再確認結果の両方を `ui_checks.json` に記録した。

## 画面と計算エンジンの一致

seed23・adaptive・40人で、実時間で14時刻進め、人物1から人物2について噂を話すボタンを押し、ステップボタンで5時刻進めた。
同じ操作をPython計算エンジンで再現し、両世界のX/A/Tがすべて完全一致することを確認した。`ui_checks.json:ui_vs_headless` に記録。
この時刻の全状態は `ui_preview_snapshot.json.gz`、実画面は `../../screenshots/gossip_effects.jpg`。

## 観測された結果

単発介入36条件と、adaptiveで10回連続の行動を試みた追加9条件を記録した。全員への行動は毎回、その時点の接続相手を対象とする。孤立していて実行相手がいない場合は、実行イベント数は操作試行数より少なくなる。

seed23のadaptiveでは、行動なしの最終的な人物1の関係数は3だった。同じ初期状態から：

| 条件 | 最終的な人物1の関係数 | 行動なしと異なる全体の辺数 |
| --- | ---: | ---: |
| 協力を1回 | 3 | 1 |
| 協力を10回試行 | 5 | 3 |
| 攻撃を1回 | 3 | 0 |
| 攻撃を10回試行 | 0 | 3 |
| 噂を1回 | 3 | 1 |
| 噂を10回試行 | 3 | 2 |

最初から孤立するよう補正したものではない。単発の攻撃は直接切断を起こさず、反復によって信頼・好感度が低下し、切断に至る条件があった。
seed30では10回の協力でも関係数は行動なしと同じ5であり、すべてのシードで同じ変化が生じるわけではない。

噂の到達人数 `gossip_reach` は「個々の噂イベントの受信者数（送り手を除く）の最大値」。10回分の受信者を足した人数ではない。
画面上の要求変化はその情報の寄与であり、他の交流を含んだ現在の評価との差を噂だけの効果とは扱わない。

全試行の数値はCSV、条件とソースハッシュはmetadata.json、再実行の一致確認はverification.json。
今回の3シードの結果は、実社会に対する統計的な一般則でも、数学的収束の保証でもない。adaptiveは観測期間内に安定条件へ達しなかった条件もそのまま `not_converged` として保存している。
