# 初期条件・行動方針の比較手順

この実験はアプリの更新式を変更せず、`adaptive` モードをヘッドレスで操作する。人物1の関係を中心に、行動なしとの差を測る。実在の人間に対する処方ではない。

## 固定した比較条件

- 人数40。初期関係密度0.05／0.10／0.20。集団ラベルは与えない。
- シード0〜5と100〜105。前者を探索群、後者を確認群とし、双方で同一の方針を実行する。結果に応じた最適化・シード選別はしない。正式な外部事前登録ではない。
- 自律交流10ステップ後の状態を複製し、各方針を60ステップ観察。時刻は介入直前を0とする。各ペアはX／A／信頼／個人属性／残り時間を完全一致させる。
- 行動なし、全接続者へ協力1回、5連続、4ステップ間隔5回、特定1人への協力5回を比較。特定の相手は、切断余裕が最小の知人／自分への信頼が最大の知人／双方の成立余裕の最小値が最大の未接続者、の3通り。対象は介入前に固定する。
- 攻撃1回／5連続、悪い噂5連続、攻撃1回後に4ステップ間隔で協力4回も比較する。噂の対象は介入前の知人のうち次数最大の人。受信者と噂の対象は区別する。
- 全員への行動の受信者集合は各操作時の接続者。切れた相手への修復を自動で試みる仕組みではない。接続者0なら全員向け行動は無操作となり、その試行も除外しない。
- 要求強度は1。時間上限1を対象人数で割り、同じ総時間の範囲で配分する。1人への集中と全員への分散では1人当たりの量が異なる。目撃者数や評判への経路も変わるので、相手の選び方だけを分離した比較ではない。
- 信頼の追加比較：密度0.10で介入直前の全ての既存関係の信頼を0.15／0.85に双方同様に設定し、攻撃1回・5連続、間隔を空けた協力、噂を比較する。非関係者への信頼は0。Xは変更しない。自然発生した信頼差ではなく、人工的に統制した条件である。
- 長期比較：同じ12シード、密度0.10、行動なし／協力5連続／協力5回間隔4／噂5連続を240ステップ観察する。60ステップ比較と同じ介入直前状態・同じ最初の行動列を使う。

現在の初期Xは非関係者への独立な正規分布N(0,0.35²)、既存関係は両方向別々の一様分布[0.65,0.90]。actor／partner効果に分解するSRMは現行コードに実装されていない。初期AはER型無向グラフ。初期信頼は既存関係に合成した事前値であり、実測の交流履歴ではない。

## 評価基準

人物1の関係数だけを成功としない。受信平均好感度、受信平均信頼、元の関係の維持、新規関係、全体の関係数・孤立者数、負の好感度、実現した交流回数を並記する。全体平均は非関係者も含み、自己評価を除く。どれかを重み付けして架空の総合「幸福度」は作らない。

関係差は異なる辺の数であり、関係が増えた数とは異なる。コミュニティはCPM＋Leidenの構造的分割。VIや集団数の差だけから、社会的な分裂・心理的な所属変更を断定しない。曖昧な所属人数も記録する。

噂の到達人数は複数イベントの受信者の和集合。発信者を除くが、途中で知った噂の対象本人は含む。同じevent_idの二重評価はない一方、各操作は別event_idなので、同じ内容の繰り返しを識別するclaim_idはない。

確認する仮説は、協力の機会費用／集中と分散・連続と間隔の差／信頼による単発と反復攻撃の違い／噂の到達と構造変化の乖離。協力による関係減少、攻撃による関係増加などの逆転も全条件で数え、起きなかった場合も記録する。式の符号から直接決まる反応と、自律更新の後に生じた結果を区別する。

## 再現性と出力

`runs.csv`は全試行、`actions.json`は実行要求、`metadata.json`は条件・実行ソースのSHA256、`initial_*.json.gz`は実際の介入直前X／A／信頼／属性。実行要求の人物IDとCSVの相手IDはPythonの0始まり。画面・文章では1始まりで表す。

`verification.json`は初期ペア一致、無操作一致、方針によらない対照世界、別実行の完全再現を検査する。初期JSONは入力確認用であり、未処理イベント・検出器の内部履歴を含む完全な単独再開ファイルではない。再実行には保存されたseed／設定／準備期間と同一ソースを使用する。

不確実性は人物40人を独立標本にせずシードを単位として扱う。3密度の結果も同じシード内で平均してからブートストラップする。12シードの小規模な記述的研究であり、未実行の初期分布・パラメータに一般化しない。

60／240ステップは観察期間で、数学的収束時刻ではない。実行上限を外して同じ期間を走らせ、終了時の観測状態も保存する。

```sh
python experiments/run_policy_study.py --trust-check
python experiments/run_policy_study.py --densities .1 --policies none,help_burst,help_spaced,gossip_burst --steps 240 --output docs/experiments/conditions-and-policies/long-horizon
python experiments/summarize_policy_study.py
python experiments/summarize_policy_study.py --input docs/experiments/conditions-and-policies/long-horizon
```

PythonにはNumPy／igraph／leidenalg、集計図にはMatplotlibが必要。今回のホスト実行はMacのPython3.10.13と既存vendorを使用した。Windowsでのこのバッチ手順は未確認。正式TOEの配布方式とは別の開発・研究用手順である。TouchDesignerの描画座標は実験の入力に用いない。
