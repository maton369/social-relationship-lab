# 人間関係シミュレーター 正式版

画面のタイトルを変更し、基本画面の情報を絞って人物欄の文字を14pxから28pxに拡大しました。「悪い噂を広める」の意味・対象・知った人数を表示します。オレンジの折れ線は通常画面から外し、行動比較だけで意味と軸の範囲を示します。シミュレーションの更新式は変更していません。

ダウンロードするのは **Social_Relationship_Lab.toe 一つだけ**です。

1. TouchDesigner 2025（Python 3.11版）をインストールし、ライセンス登録を済ませます。
2. `.toe` を書き込み可能なフォルダへ保存し、TouchDesignerで開きます。
3. 初回に必要なファイルを同じ場所の `.social_lab` へ展開し、操作画面を開きます。

サメのプロジェクト、別のTOX、リポジトリ全体、別途Python・pip・MCPの設定は不要です。
コードとMac Apple Silicon／Windows x64用ライブラリを同梱しています。通常の起動時はネット接続不要です。
記録の保存先は `.toe` と同じ場所の `exports/` です。

好感度と信頼・履歴、有限の交流時間、自律交流、噂の影響表示、中央ノードと太い関係線、行動あり／なしの比較を含みます。

以前の配布では、Mac実機のソースのないフォルダからの展開・起動・実時間再生・保存を確認しました。今回の画面変更では、MacのTouchDesigner上で協力・攻撃・噂・手動停止・1ステップ・詳細表示を操作し、自動テスト47件とTOEの展開・再梱包の一致を確認しました。
Windows用バイナリを内蔵していますが、Windows実機での描画は未確認です。

旧版のTOE・TOXは配布対象から除きました。過去の数値実験・検証ログは研究記録としてリポジトリに残しています。
